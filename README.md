# RutasKM

Proyecto Android RutasKM.

Esta rama contiene la reconstrucción mantenible de la aplicación y su cadena de compilación verificable.

Funciones objetivo:
- Registro local de conductor y vehículo.
- Registro de rutas y kilometraje.
- Recordatorio de cambio de aceite.
- Recuperación de acceso por correo mediante Supabase.
- Restablecimiento del contador de recorrido sin alterar el odómetro real ni el historial de mantenimiento.
